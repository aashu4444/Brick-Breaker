BRICK BREAKER

This is a Brick Breaker game that runs in your web browser. You move a
slab at the bottom of the screen to bounce a ball upwards and break all the red
bricks. Clear every brick and you move on to the next level, where things get a
little harder.

We made it using HTML, CSS and JavaScript.


HOW TO RUN IT
-------------

1. Unzip the project folder.
2. Open the folder and double-click the file called index.html.
3. The game opens in your browser. That's it!

Please keep all the files together in the same folder. If you move index.html
somewhere else on its own, the game will lose its styling, its code and its
sound.

HOW TO PLAY
-----------

- Press the Start button to start game.
- Use the LEFT and RIGHT arrow keys to move the slab.
- Keep the ball from falling below the slab.
- Break every brick to go to the next level.

A few things that will help you:

- Before you press Start, the ball sits on the slab and moves with it, so you
  can pick where it starts from.
- Where the ball hits the slab decides where it goes. Hit it with the middle
  and it goes straight up. Hit it with the left or right edge and it flies off
  to that side. Use this to aim at the bricks you want.
- If the ball falls, you lose one life. Press Start again to launch a new ball.
- When all your lives are gone, the game is over. Press Start to begin a fresh
  game.


SCORE, LIVES AND LEVELS
-----------------------

- You start with 3 lives.
- Every brick you break gives you points. On level 1 it's 10 points per brick,
  on level 2 it's 20, and so on. Later levels are worth more.
- Each new level has a new random pattern of bricks, a few more bricks than
  before, and a slightly faster ball. The speed stops increasing after a while,
  so it never becomes impossible.

Your score, lives and level are shown above the game box while you play.


WHAT'S IN THE FOLDER
--------------------

index.html      The game page (the box, the Start button and the sound)
style.css       How everything looks (colours, sizes, the slab, the ball)
script.js       The game itself (the ball, bricks, score, lives and levels)
audiofile.mp3   The sound that plays when you press Start
